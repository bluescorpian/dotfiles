Correct this file by rewriting the wrong claim, not by appending under it —
search and partial reads reach the original first, so a retraction sitting
under a live instruction is a trap. Delete what stopped being true rather
than annotating it.

Dated entries stacked in one file mean it has stopped being a document and
become a log. Keep the log elsewhere and let the page state one current
claim.
